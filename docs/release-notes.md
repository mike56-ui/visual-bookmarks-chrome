在本页 Assets 中下载 **visual-bookmarks-edge.zip**。

单击书签默认在新的前台标签页打开网站，原来的文件夹和滚动位置会保留。可以在「设置」中改回当前标签页打开。左侧文件夹内的网站图标缩至 16 像素，高分屏会请求对应分辨率。

拖动书签和文件夹后，其他卡片会保留已经显示的图标和缩略图。排序会静默保存，可以按 Ctrl+Z 或在设置底部点击「撤销上次排序」。

书签跨行补位时会平移并保持不透明。访问 GitHub 等网站后，扩展可以使用网页声明的 HTTPS CDN 图标。

在设置里开启「收藏时保存首张缩略图」并允许 Edge 访问网站后，新收藏的网页会保存一张首屏图，后续打开时沿用。把鼠标移到某张书签上，点击卡片左上角的刷新按钮，即可单独换图。同网址的其他书签和自定义封面会保留。要批量更新，可在设置底部点击「更新当前文件夹缩略图」。

点击搜索栏右侧的齿轮，可以在当前新标签页调整外观、操作习惯或导入导出设置。按 Esc 可回到之前的书签位置。

## 在 Edge 中安装

1. 解压 ZIP 到一个长期保留的文件夹。
2. 打开 `edge://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择包含 `manifest.json` 的解压目录。
4. 打开新标签页使用 Visual Bookmarks。

手动更新：先备份插件数据，再把新版解压覆盖到同一个目录，在扩展管理页点击「重新加载」。不要删除原来的扩展后重装。

这是开发者模式安装包，不能双击安装，也不会通过 Edge 商店自动更新。商店版需要另外完成首次上架，之后从该商店条目安装才能接收商店更新。首次从开发版迁移到商店版前请备份数据，两者可能具有不同的扩展 ID。

`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。
